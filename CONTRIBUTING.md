# Contributing

Use isolated test instances, synthetic fixtures and separate branches. Never copy production SQLite databases, config, certificates, real IP/MAC lists, screenshots containing personal data or logs into commits. Keep changes small, include regression tests and document platform limits. Do not weaken TLS, authentication, Windows security or the container isolation model for convenience. Run the commands in README before opening a pull request. NEXUS is MIT-licensed; by contributing you agree that your contributions are licensed under the MIT License. See also the [Blue Studio Labs contributing guide](https://github.com/bluestudiolabs/.github/blob/main/CONTRIBUTING.md). Report security issues through GitHub private vulnerability reporting, not public issues.
